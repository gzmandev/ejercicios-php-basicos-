# Ejercicios PHP Básicos — "Preguntas"

**Curso:** Programación Web Básica  
**Tecnología:** PHP, MySQL (mysqli)  
**Entorno:** XAMPP

## Descripción

Ejercicios prácticos de PHP: variables, condicionales, switch, formularios, conexión a BD y operaciones básicas.

## Instalación

1. Copia en `C:\xampp\htdocs\`.
2. Inicia Apache y MySQL en XAMPP.
3. Importa `bd/evaluacion_web.sql`.
4. Abre en el navegador: `http://localhost/ejercicios-php-basicos/preguntas/pregunta1.php`
